# TODO-003 verifier への依頼

仕様は `TODO.md` の TODO-003 の節。差分は `git diff src/game/game.ts`（星の描画の 1 か所）。コードは直さない。

## 目的

背景の星が縦長の長方形でなく、奥 1px〜手前 2px の正方形の点で描かれていること、
描画に欠けや余計なものが無いことを確かめる。

## 測り方

計測スクリプトは `archives/agents/TODO-003/verify-stars.mjs` に 1 本だけ作る
（`archives/agents/TODO-002/verify-fire.mjs` の起動部分と、fillRect をラップして記録するやり方を写してよい。TODO-002 のファイルは変えない）。

条件: `npm run build` のあと `npm run preview`。画面 1280x800 と 390x844（hasTouch）の 2 通り。

1. **星の大きさ（数値）**: `CanvasRenderingContext2D.prototype.fillRect` をラップし、星の描画
   （game.ts の「// 星空」のループ）で呼ばれた fillRect の w と h を 1 フレーム分記録する。
   星の呼び出しの見分け方は game.ts を読んで決め、報告に書く。
   報告する値: 星の数、w === h の割合、w の最小・最大（期待は 1〜2）
2. **見た目**: タイトル画面と、Enter で開始して 2 秒後のプレイ画面のスクリーンショットを
   それぞれの画面サイズで撮り、`archives/agents/TODO-003/` に保存する。星が点に見えるか、
   縦長のものが残っていないか、画面に欠け・余計なものが映っていないかを、画像を見て書く。
   星の一部を 4 倍程度に拡大した切り抜きも 1 枚作って見る
3. `npm test` の終了コード

各 1 回でよい（描画は条件式で決まるので繰り返さない）。

## 見なくてよいもの

星の色・数・流れる速さの測り直し（変えていない）。デザインの良し悪しの評価。

## 報告

`archives/agents/TODO-003/verifier-report.md` に、測った値と画像のパスを書く。
一致したものは 1 行、食い違いだけ詳しく。境界線上の判断は報告だけ。
返事は「終わったか・報告ファイルのパス・判断が要る点」の 5 行以内。preview サーバは終わったら止める。
