# TODO-005 verifier への依頼

仕様は `TODO.md` の TODO-005 の節（着手後に決め直した 2 点を含む）。差分は `git diff`。コードは直さない。

## 目的

スマホの操作欄が「左半分が固定のレバー、右半分が FIRE」になり、レバーの位置で速さが変わること、
操作欄の高さが仕様どおりであることを、実際にタッチ操作して確かめる。

## 測り方

計測スクリプトは `archives/agents/TODO-005/verify-lever.mjs` に 1 本だけ作る
（`archives/agents/TODO-003/verify-stars.mjs` の起動部分を写してよい。TODO-003 のファイルは変えない）。
Playwright は TODO-003 のときと同じやり方で用意してよい（プロジェクトの `package.json` は変えない）。
`npm run build` のあと `npm run preview`。

タッチ操作は、Playwright の `touchscreen.tap` では押し続けられないので、CDP の
`Input.dispatchTouchEvent`（touchStart / touchMove / touchEnd）を使う。
自機の位置の取り方は game.ts を読んで決め（描画呼び出しのラップなど）、報告に書く。

1. **操作欄の高さ**（getBoundingClientRect の値を書く）
   - 390x844・hasTouch・isMobile: `.touch` の高さ、`#lever` と `#btn-fire` の幅と左右の位置、canvas の高さ。
     期待: `.touch` は min(25dvh, 12rem) + safe-area = 192px 前後、レバーと FIRE が左右半分ずつ
   - 1920x1080・hasTouch（タッチ画面付き PC の代わり）: `.touch` の高さ。期待 192px（12rem の上限）
   - 1280x800・タッチ無し: `.touch` が出ないこと、canvas の高さ
   - 667x375・hasTouch・isMobile（横向き）: `.touch` の高さ、`#lever-knob` の幅・高さ（0 でないこと）と、
     つまみがレバー欄からはみ出していないか
2. **レバーの速さ**（390x844、Enter の代わりに FIRE をタップして開始したあと）
   レバー欄の中で、横位置を「中心」「中心から右へ半径の 50%」「中心から右へ半径ちょうど」「中心から左へ半径ちょうど」
   「欄の左端ぎりぎり」にして 0.5 秒押し続け、自機の移動の速さ（論理座標 px/秒）を測る。
   半径は `(レバー欄の幅 − つまみの幅) / 2 − 4`（game.ts の moveLever）。
   期待: 中心で 0、50% で約 107（260 × (0.5 − 0.15) / 0.85）、半径ちょうどと左端ぎりぎりで約 260（向きも書く）。
   半径ちょうどのとき、つまみが欄の中に収まっているか（はみ出していないか）も getBoundingClientRect で書く。
   自機が画面端に当たって止まると測れないので、測る前に位置を真ん中へ戻すこと
3. **指を離したら止まる**: 押したまま動かし、離した直後から 0.3 秒で自機が動かないこと
4. **同時押し**: レバーを右端寄りで押したまま、別の指（別の touch id）で FIRE を押す。
   弾が出ること、そのあいだ自機が動き続けること
5. **見た目**: 390x844 で、レバーを押していないとき・左へ寄せて押しているときのスクリーンショットを
   `archives/agents/TODO-005/` に保存し、つまみが指の位置に出ているか、欠け・余計なものが無いかを画像を見て書く。
   667x375 の横向きも、押していないとき・左端まで寄せて押しているときの 2 枚（◀ ▶ とつまみが切れていないか）
6. `npm test` の終了コード

各 1 回でよい（どれも条件式で決まる挙動なので繰り返さない）。
